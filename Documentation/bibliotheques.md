## Bibliothèques

| Bibliothèque | Usage | Installation |
|---|---|---|
| `ollama` | Utilisation du modèle Llama 3.1 pour l'analyse intelligente | `pip install ollama` |
| `pyserial` | Communication entre Python et la carte Arduino | `pip install pyserial` |
| `Flask` | Framework web pour l'interface où Rick soumet ses demandes | `pip install flask` |
| `time` | Gestion des délais dans le script Python | Incluse nativement en Python |
| Bootstrap | Mise en forme et responsive design de l'interface web | Chargé via CDN ou téléchargement depuis [getbootstrap.com](https://getbootstrap.com) |
| Google Fonts | Polices de caractères personnalisées pour l'interface web | Chargé via lien `<link>` depuis [fonts.google.com](https://fonts.google.com) |
